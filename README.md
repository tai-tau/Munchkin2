# שולחן מאנצ'קין — גרסה 2

**מערכת לניהול קלפים, לא משחק שמשחק בשבילכם.**

הכל בידיים שלכם, בדיוק כמו עם קלפים פיזיים. **הדבר היחיד שנאכף: אי אפשר ששניים יקחו את אותו קלף.**

---

## התקנה

זו תיקייה נפרדת מהגרסה הקודמת — **הישנה נשארת שלמה.**

**אפשרות א׳ — פרויקט חדש ב-Render:**
העלו את ארבעת הקבצים ל-repository חדש ב-GitHub, ואז ב-Render: `New` ← `Web Service` ← בחרו אותו ← `Build Command`: `npm install` ← `Start Command`: `node server.js` ← `Free`.

**אפשרות ב׳ — להחליף את הקיים:**
העלו את `server.js` ואת `index.html` ל-repository הקיים. **הגרסה הישנה תידרס** — שמרו עותק אם תרצו לחזור אליה.

---

## איך זה עובד

### הערימות

**במרכז השולחן שתי ערימות** — דלת ואוצר — עם מספר הקלפים שנותרו.

**לחיצה על ערימה שולפת את הקלף העליון ומראה אותו רק לכם.** באותו רגע הקלף יוצא מהערימה, כך שאם שניים לוחצים יחד — **כל אחד מקבל קלף אחר.**

**מתחת לכל ערימה יש ערימת זרוקים.** לחיצה פורשת את כולה לפי סדר הזריקה, **ואפשר לקחת משם קלף בחזרה.**

### מה עושים עם קלף שנשלף

שש אפשרויות, כל אחת גם בכפתור וגם במקלדת:

| | |
|---|---|
| <kbd>1</kbd> | קח ליד — רק אתם רואים |
| <kbd>2</kbd> | הצג לכולם — עולה למרכז השולחן |
| <kbd>3</kbd> | צייד |
| <kbd>4</kbd> | לתיק |
| <kbd>5</kbd> | זרוק |
| <kbd>0</kbd> | החזר לערימה — **הצצה בלי לקחת** |

### שני האזורים שלכם

**🛡 מצויד** — מה שעל הדמות, גלוי לכולם.
**🎒 תיק** — מה שאתכם אבל לא פעיל, גלוי לכולם.

**היד שלכם למטה — רק אתם רואים אותה.** אחרים רואים רק כמה קלפים יש לכם.

### גרירה

**כל קלף נגרר לכל מקום:** ליד, למצויד, לתיק, לשולחן המשותף, לזרוקים, **ולכיסא של שחקן אחר** כדי לצייד אותו או לתת לו.

### לחיצה על קלף

פותחת חלון עם **כל** האפשרויות, כולל "לראש הערימה" ו"לתחתית הערימה".

## מה נאכף ומה לא

**נאכף:**
קלף שנשלף יוצא מהערימה מיד · אי אפשר לקחת קלף שכבר נלקח · אי אפשר לראות או למשוך מהיד של אחר · זרוקי דלת ואוצר נפרדים

**לא נאכף — אתם מחליטים:**
תורות · קרבות וחישובם · מי יכול לעזור למי · משבצות גוף · גבול יד · דרגות ואאורה

**הדרגה והאאורה בכפתורי פלוס־מינוס.** התור מתקדם ב"תור הבא ⟵", ואפשר לדלג או לחזור כרצונכם.
